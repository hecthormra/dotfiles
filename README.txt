# dotfile-sway-
um repositorio sway dotfiles configuracao feita por ajuda de ia mais do meu estilo e testado 

==================================================
              VOID LINUX DOTFILES
==================================================

Minimalist desktop environment based on Void Linux.

SYSTEM
--------------------------------------------------
OS          : Void Linux
INIT        : runit
COMPOSITOR  : Sway
DISPLAY     : Wayland

APPLICATIONS
--------------------------------------------------
STATUS BAR  : dbar
LAUNCHER    : Rofi
TERMINAL    : Kitty
SHELL       : Zsh
BROWSER     : Zen Browser
PLAYER      : MPV
VISUALIZER  : CAVA

DIRECTORY STRUCTURE
--------------------------------------------------
dotfiles/
|
+-- sway/
+-- rofi/
+-- kitty/
+-- dbar/
+-- mpv/
+-- cava/
|
+-- README.txt

PHILOSOPHY
--------------------------------------------------
[+] Minimalist design
[+] Low resource consumption
[+] Keyboard-driven workflow
[+] Wayland environment
[+] Simple and clean configuration
[+] No unnecessary animations

INSTALLATION
--------------------------------------------------
Clone the repository:

git clone https://github.com/hecthormra/dotfiles.git

Enter the directory:

cd dotfiles

Copy configurations:

cp -r sway rofi kitty dbar mpv cava ~/.config/

NOTE
--------------------------------------------------
Back up existing configurations before copying.
